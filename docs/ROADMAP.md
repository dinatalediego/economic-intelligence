# Roadmap — evidence gates

Each stage must produce reviewable evidence before the next stage.

| Stage | Deliverable | Exit evidence | Gate |
|---|---|---|---|
| 0. Architecture baseline | Product charter, data flow, boundaries, ADR | Docs reviewed; no customer data or secret committed | Founder accepts personal-first scope |
| 1. Local macro foundation | Source registry, reproducible ingest, validation ledger | Repeatable run; counts and freshness visible; failure preserves certified data | Coverage and source terms acceptable |
| 2. Medallio founder context | Company KPI contract and manual/sanitized import | Metric meaning, grain, owner, share scope documented | Founder confirms KPI meaning |
| 3. Power BI model | Certified views and initial pages | Correct grains, reconciled totals, freshness and source shown | Founder validates decision usefulness |
| 4. Decision and value loop | Decision, action, outcome, value records | One complete evidence-linked loop | Attribution limits are clear |
| 5. Personal Supabase | Migrations, RLS, API allowlist, outbox sync | Owner and cross-owner policy evidence; idempotency, retries, restore runbook | Security review and enablement |
| 6. Shareable intelligence | Minimized views and collaboration/demo surface | Publication, source-terms, privacy, and claim review | Founder approves audience and use |
| 7. Productization learning | Reusable contract proposal for Medallio Platform | Evidence of repeated use and boundary from company OS | Company product decision |

## Priority
1. Make one personal monthly decision review faster and more evidence-based.
2. Improve trust and freshness before adding indicators.
3. Connect Medallio measures through defined, minimized contracts.
4. Test decisions and outcomes before broadening sharing.
5. Reuse learnings in Medallio Platform only after the founder workflow proves useful.

## Scope gates
A roadmap entry does not authorize connecting to client production, uploading client data, publishing a dashboard or economic claim, spending money, making commercial commitments, or deploying a public API or autonomous actions.
